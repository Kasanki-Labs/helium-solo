# Contributing

Issues and pull requests are welcome.

- Before your first pull request is merged, agree to the contributor licence agreement in CLA.md by writing in the pull request: "I agree to the contributor licence agreement in CLA.md."
- Keep each change small and focused, with a test for what it changes.
- Run the tests with `cd sdk && uv run pytest`.
- A change to the trace format needs a new format version. Open an issue first.
